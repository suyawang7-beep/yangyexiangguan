# OC 人物、卡面与素材编辑

在 `/admin` 登录后使用“OC 人物资料管理”和“16 张回忆卡资料管理”。文字保存在数据库，观众刷新页面后生效。保留现有九页视觉，不更改卡池、金币或已有参与记录。

## OC 人物

选择“＋ 新建 OC”，填写人物名称、介绍、展示顺序，保存资料后上传独立 PNG、JPEG 或 WebP 图片。数字越小越靠前；勾选“暂时隐藏”只停止公开展示，资料、图片和卡片关联保留。

新人物尚未上传图片时沿用画廊占位插画；独立图片存放在 `oc/<人物编号>.webp`，可在素材管理中调整显示位置、缩放与裁切，并查看历史图片。菜菜、吱吱保留原有介绍及两个既有立绘素材位。编辑 OC 不代表核验或授予观众岛民身份。

超过四位人物时沿用现有横向画廊，保证每位人物均可访问。

## 回忆卡

选择固定 16 张卡中的一张，编辑名称、故事和关联 OC，再保存。点击“定位并更换卡面图片”会自动选中该卡的素材位置，在下方选择图片并上传即可。

卡名、故事和关联人物会同步显示在收藏列表、搜索、详情及抽卡结果。稳定编号、稀有度、首抽规则、概率、费用和持有量不变。管理员主动留空故事会显示为空；未编辑的卡保留原故事。图片里已经画好的文字需要重新制作图片后上传；界面叠加的文字在表单编辑。

## 页面素材说明

素材选择框、缩略图及列表标明具体页面、区域、共用情况和图片建议。新增 OC 图片也会进入这套管理流程。

- 庆典共享主视觉：用于首页、未领通行证时的邀请插画，以及没有独立图片时的画廊占位；不会更换通行证免费头像。
- 收藏室统计条背景：只影响收藏种数、卡片总数和“去邮局”入口所在区域，不是整页背景。
- 肥啾邮局抽卡区背景：影响主要开信舞台，不覆盖下方卡池预览。
- 卡面素材：对应固定编号中央插画，多处展示共用；卡框、编号与稀有度仍由页面绘制。

文字按纯文本显示，不执行 HTML 或脚本。运营 JSON 导出包含 `ocProfiles`、`cardProfiles`；数据库快照包含这两张资料表，图片须另行备份。

## 接口与验收

公开读取：`GET /api/oc`、`GET /api/catalog`。管理员接口：`GET/POST /api/admin/oc`、`GET/POST /api/admin/cards`，沿用最新 main 的数据库结构与接口；图片使用原素材上传接口。

隔离测试覆盖权限、创建、编辑、排序、隐藏、图片与布局持久化、固定卡池、运营导出、参与者数据不变性，以及手机和桌面实际编辑、图片上传、公开展示与文本注入防护。测试使用独立数据库，不操作生产参与者。
