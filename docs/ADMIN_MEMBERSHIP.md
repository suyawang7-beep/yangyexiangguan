# 后台分页面、岛民认证与清理工具

## 后台导航

在 `/admin` 登录后进入概览。顶部导航中的每个部分都有独立地址：活动时间、兑换码生成与统计、公告、视效、参与者列表及详情、岛民认证、游客管理、操作记录、OC、卡片、素材、素材检查、备份导出和原测试清理。每次只显示对应页面，支持浏览器前进和后退。刷新或新开页面需要重新填写管理密钥，密钥不写入网址或浏览器持久存储。

## 岛民认证

观众打开 `/verify.html`，先登记或登录通行证，再填写抖音号。申请后会显示认证码。申请人应使用填写的抖音账号向岛主私信认证码；管理员在抖音上核对正式入团状态和账号归属，再到 `/admin/members` 勾选核验确认并通过。没有自动查询抖音入团的接口。

可通过、驳回或撤销认证。驳回和撤销须填写原因。申请一旦重新提交，旧认证码作废，旧审核请求会被拒绝。一个抖音号不能同时认证多个账户。

未经过认证的旧账户仍为游客；部署不批量修改参与者、金币、签到或收藏。游客可以浏览、登记、登录并读取已有记录，签到、兑奖和抽卡须认证通过后参与。服务器会检查身份，直接请求接口也不能绕过。活动时间和原奖励规则继续适用。撤销后停止新的参与操作，原有记录仍可读取。通行证纪念图片显示保存时的身份，不是登录或核验凭证。

抖音号、申请说明和认证码仅本人及管理员可读；运营 JSON 仅导出认证状态及时间，排除抖音号和私密申请内容。完整数据库备份含这些资料，应保密保管。

## 删除游客

在 `/admin/visitors` 查询游客，逐个勾选，最多50位。先预览姓名、编号、金币余额及各类记录数量，再点击执行并输入“确认删除所选游客”。

按用户已确认的范围，会永久删除所选游客的账户、会话、金币流水、任务、签到、抽卡和认证申请；该账户已消费的兑换码作废，不会重新变成可兑换代码。已认证岛民在列表和服务端均受保护。

执行前自动创建完整 SQLite 一致性快照。备份空间不足或备份失败时不删除。预览5分钟有效，预览后资料或认证状态改变时必须重新预览；改勾选后过期的网络响应不会启用执行按钮。删除后会话和恢复凭证均失效。没有自动一键清空全部游客的功能。

## 清除后台操作记录

在 `/admin/audit` 选择北京时间截止时间，先预览，再输入“确认清除后台操作记录”。只删除该时刻以前的 `admin_audit` 管理日志，不触碰参与者、金币、签到、抽卡或认证资料。执行前同样强制备份，并保留本次清除的新管理记录。修改时间或记录发生变化后须重新预览。

以上清理工具均由管理员手动触发。开发和验收使用独立临时数据库；发布代码不表示已经清理生产数据。

## 接口

- 本人：`GET /api/membership`、`POST /api/membership/apply`。
- 管理：`GET /api/admin/memberships`、`POST /api/admin/memberships/review`；审核须携带当前认证码。
- 游客：`GET /api/admin/visitors`、`POST /api/admin/visitors/preview-delete`、`POST /api/admin/visitors/delete`。
- 日志：`POST /api/admin/audit/preview-clear`、`POST /api/admin/audit/clear`。

所有管理接口均保留管理员鉴权；预览凭据只绑定预览时的目标和内容，不能自行更改执行范围。
