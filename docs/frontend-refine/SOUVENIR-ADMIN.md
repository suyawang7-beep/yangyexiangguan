# 纪念品素材区候选

入口：海岛控制台 → 纪念品素材。本机隔离预览 http://127.0.0.1:4217/admin/v2/ 。

复用原管理员鉴权、会话及审计，支持按物品完整名称绑定 WebP、图片预览、搜索、说明、来源授权及版本冲突检查。上传最大4MiB，内容哈希URL避免旧图缓存。新表 souvenir_assets 只存素材元数据；图片存独立素材目录的 souvenirs 子目录。未更改发放、领取、金币或库存规则。

API：GET /api/admin/souvenir-assets；POST /api/admin/souvenir-assets/save，参数 itemName/description/license/expectedRevision/confirmed，上传时带base64。响应返回items，含imageUrl、revision、updatedAt。编辑不上传图片时保留旧图。名称修改建立新绑定。静态图片由 /assets/souvenirs/{sha256}.webp 提供；只有当前目录引用的文件可访问。

验证：实际浏览器通过原登录进入、选择素材、预览、二次确认保存，服务端返回v1并记录审计。匿名请求被原鉴权拒绝。Node测试覆盖格式拒绝、版本冲突、保留原图、审计失败事务回滚、路径校验，原任务测试仍通过。手机未单独完成浏览器验收。

范围与缺口：当前仅后台素材库。个人中心纪念架尚未接入此图片映射，不能声称用户端已显示新图。未做删除、发布审批、历史版本恢复。刷新/离开浏览器有未保存提醒，模块内清空/切换素材有确认；跨后台导航的未保存提醒仍需补齐。WebP沿用现有素材模块的容器校验方式，未新增图片解码服务。

仅在独立测试SQLite/素材目录运行。未部署、未迁移生产。集成前需审查新增表、素材目录备份与用户端消费契约；不得直接替换生产数据库。回退前端入口即可停止使用，保留素材表及文件以防丢失，不回滚用户流水。
