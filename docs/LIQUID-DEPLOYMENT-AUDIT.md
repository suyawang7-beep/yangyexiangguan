## 实际发现并修正的遗漏

1. 同步最新 main 后，未登录访问事务所时找不到 `#task-dialog`，写作表单绑定抛异常，导致渲染通知未完成；实测背景和主面板均未安装。沿用 PR #2 保护后重新检查为零异常。
2. 正式认证页由 `membership-client.js` 另行生成 `#membershipApplication`。它已有玻璃面板，但不在主背景容器列表；本轮将该容器加入统一液态背景／呼吸管理，未改认证数据逻辑。
3. 手机信箱原有 `aside>:not(nav){display:none}` 把新明信片隐藏；已针对明信片恢复显示，不改变信件目录行为。
4. 扇形收藏展示隐藏了源网格；新空状态已同时加入实际显示的展馆，保留原来的引导文字。
5. 连续重播绘画视频时，旧 play Promise 可能暂停最新播放；已修复并保留单独回归测试。
6. 手绘签到章只认实际“今天已签到”状态，不把会员认证锁定导致的 disabled 当成签到成功；以临时服务／未认证测试账户复现后修正。未改七日纪念规则、会员门槛或奖励。
