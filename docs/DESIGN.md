# 不吱岛 · 菜菜岛主生日庆典 — Design System v0.1

> 本项目唯一开发仓库：`suyawang7-beep/yangyexiangguan`。旧版 `caicai` 仅作历史参考，不同步代码。
> 设计目标：海洋幻想 × 二次元插画 × 虹彩毛玻璃 × 少量手绘交互细节。
> 视觉比例（方向建议而非计算指标）：70% 冰透海洋、20% 角色插画、10% 手绘细节。

## 不可更改的世界观
- 「雾岛吱菜Gina」由菜菜与吱吱共同使用；本次生日主角是 **菜菜**，吱吱是搭档／共同岛主，而非双人生日。
- 首页文字：**🐭雾岛吱菜Gina 🐭の诞生日！**
- 副标题：**完成庆典任务领取金币，收集与菜菜的生日回忆吧！**
- 双人主海报需要给两个人都留出完整视觉位置；角色图片不得被玻璃卡片挡脸。
- 金币只作为活动积分，不充值、不提现、不做消费排行；网页访问不等于粉丝团资格。

## 颜色（具体数值见 `src/styles/tokens.css`）
冰透海蓝 #A8D8F0、浅青 #C9F4FF、虹彩紫 #CDBDFF、珠光粉 #F9C8E5、玻璃白 #F5FBFF；深海文字 #285777。
保留浅蓝主色；粉紫作为小面积虹彩点缀，不把背景改成粉紫主色。

## 排版与层级
- 大屏首页：非对称分区 + 大幅双人海报。海报为最重要视觉焦点；信息卡片分布于两侧和下方。
- 视觉深度顺序：动态海洋背景 → 柔光/气泡 → 双人主海报 → 玻璃功能面板 → 手绘小装饰/状态反馈。
- 透明卡保持足够文字对比度；不靠颜色单独表达领取／锁定／失败。
- 字体：主标题站酷快乐体；标签霞鹜漫黑；正文霞鹜文楷；加载失败回退 PingFang SC / Microsoft YaHei / sans-serif。
- 手机端海报和操作入口纵向排列；不允许遮挡主角面部。

## 组件规范
- `.buzhi-glass`：浅色半透明、柔和毛玻璃、顶部内高光、浅描边、蓝灰柔影。
- `.buzhi-button`：分 primary / secondary / reward；手绘边框只做轻量点缀；hover 与 pressed 状态有明确反馈。
- `.buzhi-tag`：短标签与活动状态。
- 特效启用 `prefers-reduced-motion` 适配，所有关键操作支持键盘焦点。
- 内容图与角色插画必须保留来源、授权与替换位置，不能默认将参考图视作可商用素材。

## 各页面
- 庆典码头：首页、双人海报、公告摘要、快捷操作入口。
- 岛民事务所：任务列表、完成代码核验、金币与任务阶段奖励。
- 签到：海洋场景、弯曲签到轨迹、足迹、连续七天隐藏奖励。
- 肥啾邮局：抽卡体验；一次 50 金币，首次保底 SR/SSR；区别于「岛主信箱」。
- 回忆收藏室：16 张卡片、稀有度、已获得/未获得、首次获得时间。
- 岛主信箱：公告中心；首页公告与信箱使用同一数据源。
- 生日通行证：独立参与者 ID；访客与核验岛民身份分离。

## 动效优先级
1. 主海报深度与缓慢水光（支持关闭）
2. 功能卡轻悬浮与聚焦
3. 翻页／撕胶带／抽便签（使用于真正需要的入口）
4. 抽卡稀有度光效
避免全部页面同时运行动画导致卡顿或晕动。

## 不做
不要纸张奶油白主体、硬黑粗描边、普通 SaaS 组件堆叠、过度极简、只有光效没有交互、强制背景音乐。
