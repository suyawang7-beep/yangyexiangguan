# 回忆收藏室细化 · 本地验收

本轮仅完成回忆收藏室，未部署、未改生产数据或素材。

## 已实现

- 封面突出真实独立收藏数、总持有张数和收藏进度。重复卡只增加总张数；目录或账户未完成加载时使用未知状态，不显示虚假进度。
- 保留原扇形、圆环、拖动及前后按钮；展示方式按钮仍遵从后台配置。按用户要求，基础完整网格始终保留在展台下方。
- 展台增加当前卡片稀有度、角色、数量及“查看这段故事”，沿用现有详情弹窗；关闭详情回到触发按钮。
- 拥有状态、稀有度和卡名/角色搜索继续联动展台及网格；增加结果数、清空筛选，空结果禁用故事入口。
- 手机搜索与稀有度独立一行，输入16px，主要操作44px以上，320/390宽度无横向溢出。
- 本页新增CSS，沿用海蓝色及奶油白相册风格；展台过渡缩短，支持全站动效开关及系统减少动态。
- 60卡定义、抽卡概率、金币、后台卡面配置及历史稀有度不变。未改首页或个人中心布局。
