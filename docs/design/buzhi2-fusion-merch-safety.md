# 融卡工坊与周边兑换店：测试版实现说明
- 版本：2.0 开发分支，**未部署至腾讯云正式站**。
- 正式版 server/index.mjs 经代码核对当前有抽卡与任务/金币码兑换接口，**没有可确认的融卡交易或实体周边兑换后端路由**。
- 融卡页面：选演示卡→素材台显示→规则核对（卡张数/重复/金币/合成结果均待确认）→禁用确认。演示卡不是用户资产，不调用服务端。
- 商店页面：展示演示商品位→选中商品→核对库存/资格/消耗（全部待服务端配置）→禁用确认。不创建订单、不读取真实库存。
- 正式接入前必须设计事务模型：资产及库存原子扣减，服务端验证库存和兑换资格，幂等请求号，确认与取消，超时查询交易记录，管理员履约与撤销/退款规则，失败回滚，审计日志。
- 不从现有 /api/redeem、/api/redeem-coin-code 推断可以完成实体周边兑换；那两个接口承担不同业务。
- 最终文案、视觉素材、融卡规则、商品目录与数量由岛主确认。
