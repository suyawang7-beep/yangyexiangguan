# 不吱岛 2.0 · 工程集成说明（2026-10-27）

## 来源
- 工程基础：`feat/buzhi2-multipage-foundation-20261027`，八个独立页面以及安全演示行为。
- 视觉与交互交接：`codex/shared-web-skills-20261027`，`docs/design/2026-10-27-handoff.md`。
- 本分支是单独的集成工作分支，**不是对任何来源分支的整枝合并**。

## 已复用
- 把生日专题拆为独立的 `birthday.html`，首页通过普通链接进入。
- 复用隔壁生日书桌的可访问标签模式：`role=tab/tabpanel`、`aria-controls`、`aria-selected`、`tabindex`、`hidden`；支持 click、ArrowLeft、ArrowRight、Home、End。
- 回忆、事务所、导览都指向本 `ui-preview/buzhi2/` 内的独立页面，避免意外回到旧版单页。
- 手机可操作区域以44px为最低目标、统一焦点样式、保留减少动态控制；**需浏览器实测才可声称通过**。
- 活动日期、规则及开放状态均保留待确认占位。

## 暂未复用
- 隔壁生日预设的视觉 CSS 和现有双人角色占位不直接移植：用户明确不喜欢固定左右分栏的旧布局。
- 未将隔壁的整套 docs/vendor、GSAP 或 StyleKit 作为运行依赖；只复用适用的交互思路。
- 未读取或改写任何生产数据库、卡池、金币、认证、真实邮箱或任务记录。
- 现有正式项目仍是 Node 后端和已上线页面；本预览用 nginx 静态容器。禁止将分支 Dockerfile 直接合并进 main。

## 给隔壁视觉侧
- 可重做所有页面的 HTML 结构、图像和 CSS，不必保留现有卡片、标题左右结构。
- 保留页面路由 URL、按钮用途、语义标签和键盘交互挂钩；在设计变更时同时更新测试。
- 首页只做世界观入口，生日邀请单独在 `birthday.html`；`workshop.html`/`shop.html` 为独立工坊和商店页面。
- 实际交易按钮在未确认规则和服务端接线前必须禁用；不得用假成功文案代替后端响应。
- 视觉素材必须经核实，保留角色特征：吱吱蓝灰长发、仅刘海薄荷绿挑染、蓝粉瞳与发带；菜菜银白及肩短发、宝蓝瞳、小圆角。

## 验收清单（待执行，不虚报）
1. 首页到生日专题/融卡/商店、各独立页面跳转无404。
2. 生日书桌 tab 鼠标及键盘导航正确；非当前 panel 不可见。
3. 320、375、390、768和1440像素尺寸下无横向溢出、按钮不重叠。
4. 模拟规则未知、无登录和服务端无响应时，无可执行真实交易。
5. CSS 提升字号后仍可读；减少动态模式无持续运动。
6. 视觉素材加载前仍有可用的页面内容与替代说明。
