# 手机口袋卡册发布

基于已在线的每日融卡版本 3056d160d902aea701daf31340861f9db60902b3，保留全部原有提交。

手机端（680px及以下）采用每页4张的口袋卡册、单卡欣赏、相遇记录三个标签，筛选和故事使用原生弹窗。卡名、等级、故事、持有量及抽卡/融卡记录均来自现有应用状态，没有示例数据注入。展示组件使用 Shadow DOM 隔离样式，桌面原有收藏展台和每日融卡入口保留。短屏允许自然滚动，不限制页面缩放。

不修改后端、SQLite结构、金币、卡池定义、融卡规则、后台及主页；组件没有写入API请求。

验证：`node tests/collection-pocket-live.cjs`、`node tests/card-profile-loading.cjs`、`node tests/card-fusion.cjs` 通过。覆盖真实API加临时数据库、60卡目录、收藏与历史、故事弹窗、筛选、320/390/1440布局、融卡幂等及不可变历史。手机硬件触感仍需用户实际设备反馈。

发布顺序：打包并核对清单；上传核对哈希；核对当前版本后停服；新SQLite安全备份和素材/代码备份；异机加密转存、哈希校验及隔离恢复演练；切换新目录并启动；只读核对版本、页面、目录、资源与数据库完整性。沿用已有部署脚本，失败时停止新版本并保留回滚目录及快照，不把旧数据库覆盖到已有新活动的数据上。

`docs/design/previews/collection-pocket.html` 是独立示例预设；正式入口是 `collection.html`，由 `collection-pocket.js` 接收真实状态。
