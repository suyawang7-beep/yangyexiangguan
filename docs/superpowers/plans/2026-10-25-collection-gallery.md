# 回忆收藏室细化

用户已确认继续下一项收藏室细化，并授权本地开发。基于已上线个人中心，独立分支 `codex/collection-gallery-20261025`。

**Goal:** 海盐蓝与奶油白的生日回忆展馆，突出真实收藏进度与选中卡片信息，同时保留现有扇形/圆环和完整网格。

**Architecture:** 原生HTML/CSS/JS，沿用app.js的账户、目录、筛选及详情逻辑；effects.js继续负责展台。仅collection.html加载新CSS，body标记限定新的展馆行为，不改其他页面。无新增依赖、后端或数据库变更。

**视觉:** 沿用蓝色文字、玻璃底与奶油白纸张，标题32–40px、正文14–16px、按钮至少44px；手机筛选两行布局，输入16px。展台只做200–260ms动作反馈，尊重减少动态及全站开关。不增加持续漂浮装饰。

**边界:** 不改60卡定义、概率、金币、持有数量或历史稀有度；不操作生产，不实施OC绑定或其他页面改版。

- [x] collection-gallery.css限定本页，整理封面、筛选、展台、卡片说明和网格，手机精简高度并保留触摸反馈。
- [x] 运行新增测试及card-profile-loading、mobile-experience必要检查；截图并审查，提交独立分支/PR供查看，不直接部署。

## 容易遗漏的状态

- 账户或目录未加载时不显示虚假的0收藏进度；目录失败保留错误提示。
- 空筛选同时更新展台、结果数和网格；清除筛选必须同步输入、按钮和稀有度。
- 当前卡片信息使用安全文本/已有转义，隐藏卡不进入键盘焦点；详情关闭回到触发按钮。
- 匿名可浏览目录，不能伪装成有收藏；重复卡只增加总张数。

collection-gallery（320/390/1440、筛选/详情/加载失败/无业务写入）、card-profile-loading、mobile-experience均通过。只读审查无重要问题；已更新effects脚本缓存版本。未操作生产。
