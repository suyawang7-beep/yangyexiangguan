# Island identity and original vector stickers

`island-mark.svg` is the shared island/sun/palm/wave site mark. It replaces the previous bird-character mark in navigation and is also the favicon. The bird courier remains part of the post office, not the site logo.

`island-stickers.svg` contains six original SVG symbols: `jellyfish`, `shell`, `bottle`, `orbit`, `cloud`, and `postcard`. They reference the user's boards only for pastel blue/pink/lilac palette, sea motifs, white sticker edges and soft highlights. No supplied-image pixels, watermarks, app logos, artist signatures or sample-sheet labels are copied or removed. These symbols are decorative objects, not new islander OCs or official card artwork.

Room assignment: office gets a little message window and star orbit; gallery gets a jellyfish and pearl shell; mailbox gets a letter window and cloud; collection gets shell/orbit; other pages receive at most two quiet accents. The same site identity is retained while headings and placement vary.

Decorations are marked `aria-hidden`, ignore pointer events and remain static. No extra animation loop, remote image request or library is introduced. Mobile placement keeps title text and controls readable; the glass/water backgrounds remain the existing ones.
