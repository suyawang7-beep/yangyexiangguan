# 不吱岛多页面 UI 演示

本目录是独立可运行的网页预览，不修改主网站入口，不连接正式 Node / SQLite 后端。

打开 `index.html` 可看首页。推荐通过静态服务打开，以便不同页面共享同一浏览器的演示记录：

```sh
python3 -m http.server 5174 --bind 0.0.0.0
```

在预览工具中打开端口 5174 的 `/ui-preview/index.html`。

## 页面

- `index.html`：庆典码头
- `passport.html`：生日通行证
- `office.html`：岛民事务所（任务操作明确标记为本地演示）
- `checkin.html`：按北京时间的签到
- `draw.html`：50 金币单抽、首次6张 SR/SSR 等概率、正常16张等概率
- `collection.html`：收藏、搜索、筛选、卡片详情、最近抽卡记录
- `mailbox.html`：统一公告样例
- `effects.html`：特效体验入口，建议先从这里查看新版
- `guide.html`：可跳过的独立登岛地图导览
- `islanders.html`：未来 OC 的轮播、错落与空间布局示意

所有页面共享 `styles.css` 和 `app.js`，使用真实独立 HTML 页面导航。`localStorage` 键为 `buzhi-ui-preview-v3`，只保存在当前浏览器；不是正式账户、岛民核验或真实领奖服务。首次登岛赠送50演示金币。免费报到不重复发放首次奖励。正式上线前必须接入后端，由服务端负责金币、概率、核验与账户恢复。

`assets/island.svg` 与卡面矢量图形为本次预览原创示意，非正式角色设定或正式卡面。`round1` 字体改为随站点分发的圆润中文字体 `Buzhi Rounded`（寒蝉全圆体的 OFL 改名 WOFF2 衍生版），不再请求 Google Fonts；加载失败使用中文系统无衬线回退。来源、许可和固定版本见 `assets/fonts/README.md`，字形不改造为角色素材。

`celebration.css` 由 `styles.css` 引入，各页改为登记处、任务公告栏、日历、相册展馆、角色海报、信件架、地图旅程和光影游乐场的不同构图。`app.js` 中 `applyPageLayout()` 仅重排展示，原有表单、控件、ID 和活动规则保留。收藏默认模式与选中状态已对齐，手机领取／签到操作及 OC 名字前置。首页手机端将人物放到文字与主要操作之间，不恢复已删除的四张大入口卡片。

StyleKit Skill 0.8.0 的设计原则和移动端指南用于本次实现。在线风格 API 访问返回403，因此没有声称获取或通过在线风格规格验收。

## 特效版本

新增 `effects.js` / `effects.css`，按用户提供的参考思路用原生 Canvas / WebGL / CSS 实现，不需要远程 GSAP、Three.js 或调参面板。

`glass-surfaces.css` 为各页面板和 OC 展示卡提供统一通透毛玻璃；表单和按钮保留更清晰的底色。用户暂缓调整的回忆卡本体、图案、稀有度和卡背样式不在此文件的修改范围内。

抽卡页单独加载 `draw.css`：不再使用其他子页的编号式版头，改为邮局小栏、居中来信舞台、邮戳和紧贴卡片的金币／操作区。手机优先显示抽取或领取通行证入口，概率说明保留在操作区下方。只调整展示与卡片整体缩放，不修改卡面内容、抽卡价格或概率。

`courier1` 在此基础上加入肥啾叼卡、约三秒的送达演出和生日流星雨（电脑 18 条、手机 10 条）。预览先保存结果再演出；关闭动效、系统减少动态效果或页面进入后台会直接揭晓。它仍是本地演示，不能把这套本地结算搬到正式账户。全站状态及两边接线差异见 [`docs/不吱岛_全站页面与开发交接_2026-10-17.md`](../docs/不吱岛_全站页面与开发交接_2026-10-17.md)。

该页的最小布局与流程检查：在仓库根目录运行 `node tests/ui-preview-draw.cjs`，需要可导入的 Playwright 和 Chromium（可通过 `CHROMIUM_PATH` 指定浏览器）。检查 320／375／390／768／1440 宽度、首抽、收藏保存、金币不足和未领取通行证的入口；只使用隔离的本地演示记录，不连接正式账户。

首页另加载 `island-home.css` 和原创 `assets/island-scenery.svg`：被大海环绕的生日海岛、漂云、树叶、海岸波纹和帆船，配合真正的局部毛玻璃。所有新增动效仍受统一开关和系统减少动态效果控制，其他页面不加载首页专用样式。

- 首页 WebGL 水面折射（本地生成海面纹理，不加载第三方图片；不支持 WebGL 时保留 CSS 水波）
- 星光鼠标，手机点击粒子，保留表单与弹窗的原生光标
- 收藏网格 / 扇形 / 圆环，按钮、键盘和拖动切换，原有筛选与详情保留
- 任务进度肥啾、待抽卡波浪、开卡粒子扫光、签到短暂粒子
- 原创地图路径巡游，不改变其他页面的独立导航结构
- OC 预留布局仅为示意，没有创建或宣称真实岛民 OC

统一动效开关与系统减少动态效果均控制新增效果；页面不可见时暂停持续绘制。资源来源、适配与验收边界详见 `MOTION-NOTES.md`。
