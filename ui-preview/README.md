# 不吱岛多页面 UI 演示

本目录是新版多页面界面的共用来源：GitHub Pages／静态服务打开时为独立演示；正式 Node 服务提供这些页面时接入真实账户与 SQLite 数据。旧界面保留在 `/legacy`，不要用根目录旧 `index.html` 覆盖新版。

`sticker1` 为各页增加不同字体与位置的版头：事务所居中公告牌、画廊右侧手写标题、收藏相册封面、信箱来信与签到日期。正文圆体保留，新增两款标题字体子集合计约 50 KB，随站点分发，来源与 OFL 许可见 `assets/fonts/README.md`。全站标志和 favicon 使用原创海岛，六种原创 SVG 贴纸不复制参考图像素；说明见 `assets/STICKERS.md`。装饰不遮挡操作、不参与朗读，也不新增持续动画循环。局部检查：`node tests/ui-preview-draw.cjs --headers-only`。

`ticket1` 将领取后的通行证改成横向纪念票：左侧庆典头像票根，右侧昵称、生日、庆典区间、唯一编号与未核验标记。主参考是用户第三张图的纸纹／邮票印章，结合第二张票根缺口和第一张排版；只借鉴材质与构图，不复制人物、游戏标志或图片像素。纸面是冰白浅蓝的细纹纸，仅用于纪念票，不替换全站毛玻璃。`passport-ticket.js` 在浏览器本地一次性绘制真实 2400×1200 PNG，页面和长按保存预览使用同一图片；下载不依赖第三方截图服务。新增样式仅在通行证页加载。

点击“保存纪念通行证”打开图片，再下载或在手机长按保存。图片只作纪念，不能登录，也不作为核验凭据；恢复密钥、令牌、完整平台 UID 不传入绘图器。当前正式账户接口没有可信核验字段，因此仍显示访客／未核验；演示任务权限不能改变这个标记。正式头像持久化仍属原有待办，本轮没有改后台协议。新登记／老岛民找回入口与首次 50 金币规则保留。局部检查为 `node tests/passport-ticket.cjs`，覆盖真实 PNG 下载、四种宽度、长昵称与隐私字段排除；正式接线见 `tests/production-layout.cjs`，只用临时账户与数据库。

`signature1` 按用户补充，只把纪念票中的昵称改为手写体，形成亲笔签名与说明文字的区别。标题原有风格保留，短句、说明、日期和编号不改；下载图同步。昵称使用自托管、按名字所需字符加载的 OFL 文楷字库，避免只套用标题的小字库导致中文名字仍显示旧字体。来源与生成方法见 `assets/fonts/README.md`。

`ticket-motion1` 只给已生成的票面预览增加一次 800ms 的轻落入场，以及电脑鼠标悬停时上抬 5px／柔和阴影；不跟随鼠标摆动，不循环播放。手机不启用悬停，保存／下载／复制按钮提供轻微按压反馈。全站开关、系统减少动态效果和切到后台都会取消正在播放的入场，重新开启不会重播；组件替换时清理动画和事件。PNG 在播放前已生成，保存预览和下载仍使用同一个静态图片，不改字体或账户数据。局部检查 `node tests/passport-ticket.cjs --motion-only`；原有静态保存检查仍为不带参数的同一命令。

`sea2` 只为首页庆典标题增加中文艺术字 `Buzhi Playful`（ZCOOL KuaiLe 的 OFL 改名子集，4.3KB），保留事务所粗黑公告牌、画廊手写标题及通行证昵称字体，不把艺术字用于正文。海洋原创 SVG 扩展到 14 种，新增落日、海浪、灯笼、海星、月亮海面、旋涡海、透明胶带与微光枝叶；十个页面分别组合四枚较大的装饰，穿插在内容之间，没有恢复已删除的首页入口／故事卡，也不增加持续动画。来源与分配见 `assets/STICKERS.md` 和 `assets/fonts/README.md`。检查 `node tests/ui-preview-draw.cjs --decor-only` 覆盖十页电脑／手机、真实艺术字体、装饰不拦截操作、无横向溢出、原有差异化标题和画廊按钮。卡背／边框的新参考图尚待确认，本轮未修改奖励卡样式。

`moon1` 在用户确认黑金月亮许愿签参考后，新增原创 `assets/memory-card-back.svg` 和透明 `assets/memory-card-frame.svg`。卡背为浅纸外沿、深海星空拱窗、月亮／星盘和海岛纹章；所有待抽卡共用相同卡背，不透露稀有度。正面只增加细金线边框，保留原图、卡名、稀有度、数量和背景色。`card-mystery.css` 由共用样式引入，覆盖抽卡预览／揭晓、收藏和详情，未改变整站配色、后台素材接线或抽卡结算。素材边界见 `assets/CARD-DESIGN.md`。针对性检查 `node tests/ui-preview-draw.cjs --mystery-only` 覆盖四种宽度、真实 SVG 载入与深浅对比、同一卡背、前框不拦截点击、50 金币／首抽保障、收藏筛选与详情；仅使用隔离本地身份。

打开 `index.html` 可看首页。推荐通过静态服务打开，以便不同页面共享同一浏览器的演示记录：

```sh
python3 -m http.server 5174 --bind 0.0.0.0
```

在预览工具中打开端口 5174 的 `/ui-preview/index.html`。

## 页面

- `index.html`：庆典码头
- `passport.html`：生日通行证
- `office.html`：岛民事务所（按运行模式使用演示任务或服务端任务与账本）
- `checkin.html`：按北京时间的签到
- `draw.html`：50 金币单抽、首次6张 SR/SSR 等概率、正常16张等概率
- `collection.html`：收藏、搜索、筛选、卡片详情、最近抽卡记录
- `mailbox.html`：静态公告样例／正式服务公告
- `effects.html`：特效体验入口，建议先从这里查看新版
- `guide.html`：可跳过的独立登岛地图导览
- `islanders.html`：未来 OC 的轮播、错落与空间布局示意

所有页面共享 `styles.css` 和 `app.js`，使用真实独立 HTML 页面导航。静态演示的 `localStorage` 键为 `buzhi-ui-preview-v3`，只保存在当前浏览器，不代表正式账户或核验。演示首次登岛赠送50金币，既有报到记录不重复发奖。

正式服务注入 `window.__BUZHI_PRODUCTION__` 标记，注册、登录、恢复、金币、任务码、签到、抽卡、收藏、账本和公告已接服务端；正式模式不读取演示账户记录，也不会在接口失败时退回本地发奖。已登录不等于已核验岛民；核验、头像持久化、OC 详情和实体组合兑换仍需后续完成。已接线不代表公网生产验收完成。

`assets/island.svg` 与卡面矢量图形为本次预览原创示意，非正式角色设定或正式卡面。`round1` 字体改为随站点分发的圆润中文字体 `Buzhi Rounded`（寒蝉全圆体的 OFL 改名 WOFF2 衍生版），不再请求 Google Fonts；加载失败使用中文系统无衬线回退。来源、许可和固定版本见 `assets/fonts/README.md`，字形不改造为角色素材。

`celebration.css` 由 `styles.css` 引入，各页改为登记处、任务公告栏、日历、相册展馆、角色海报、信件架、地图旅程和光影游乐场的不同构图。`app.js` 中 `applyPageLayout()` 仅重排展示，原有表单、控件、ID 和活动规则保留。收藏默认模式与选中状态已对齐，手机领取／签到操作及 OC 名字前置。首页手机端将人物放到文字与主要操作之间，不恢复已删除的四张大入口卡片。

`office1` 删除事务所待办横条与报到任务卡，仅展示其余六张任务卡。电脑双列高低错落，手机单列左右轻错位，保留阅读顺序与不重叠的操作区域。历史报到、奖励和金币账本不删除；肥啾进度从独立计数读取。局部检查使用 `node tests/ui-preview-draw.cjs --office-only`，不必每次跑十页。

`passport1` 在未登录的登记区提供“新岛民登记 / 欢迎老岛民”切换，原来下方独立的找回卡片移除。原注册表单与正式登录接口保留，切换不重复发金币，已登录者仍显示自己的通行证。静态 Pages 的找回区域只读展示，不接收真实恢复密钥。局部检查为 `node tests/ui-preview-draw.cjs --passport-tabs-only`；隔离正式恢复流程见 `tests/production-layout.cjs`。

StyleKit Skill 0.8.0 的设计原则和移动端指南用于本次实现。在线风格 API 访问返回403，因此没有声称获取或通过在线风格规格验收。

## 特效版本

新增 `effects.js` / `effects.css`，按用户提供的参考思路用原生 Canvas / WebGL / CSS 实现，不需要远程 GSAP、Three.js 或调参面板。

`glass-surfaces.css` 为各页面板和 OC 展示卡提供统一通透毛玻璃；表单和按钮保留更清晰的底色。用户暂缓调整的回忆卡本体、图案、稀有度和卡背样式不在此文件的修改范围内。

抽卡页单独加载 `draw.css`：不再使用其他子页的编号式版头，改为邮局小栏、居中来信舞台、邮戳和紧贴卡片的金币／操作区。手机优先显示抽取或领取通行证入口，概率说明保留在操作区下方。只调整展示与卡片整体缩放，不修改卡面内容、抽卡价格或概率。

`courier1` 在此基础上加入肥啾叼卡、约三秒的送达演出和生日流星雨（电脑 18 条、手机 10 条）。静态演示先保存本地结果再演出，正式模式等待服务端保存结果后演出；关闭动效、系统减少动态效果或页面进入后台会直接揭晓，动画不再随机结算。全站状态及两边接线差异见 [`docs/不吱岛_全站页面与开发交接_2026-10-17.md`](../docs/不吱岛_全站页面与开发交接_2026-10-17.md)。

`bird1` 只追加肥啾按钮互动：等待时打盹，鼠标／键盘选中时探头，手机点按可直接送达，揭晓时短暂庆祝。使用本站已有白色肥啾，不更改真实按钮与结算；减少／关闭动效时静止。参考来源见 `MOTION-NOTES.md`，局部检查为 `node tests/ui-preview-draw.cjs --bird-only`。OC 与首页水波候选尚未加入。

集中布局与流程检查：在仓库根目录运行 `node tests/ui-preview-draw.cjs`，需要可导入的 Playwright 和 Chromium（可通过 `CHROMIUM_PATH` 指定浏览器）。覆盖十页手机／电脑渲染、真实圆体加载、320／375／390／768／1440 宽度的抽卡、首页手机首屏、首抽与收藏、任务码和动效开关；只使用隔离演示记录。`node tests/production-layout.cjs` 另以临时 SQLite 与临时账户检查正式模式字体、注册、抽卡、收藏、签到、账本和公告，不触碰线上数据库。

首页另加载 `island-home.css` 和原创 `assets/island-scenery.svg`：被大海环绕的生日海岛、漂云、树叶、海岸波纹和帆船，配合真正的局部毛玻璃。所有新增动效仍受统一开关和系统减少动态效果控制，其他页面不加载首页专用样式。

- 首页 WebGL 水面折射（本地生成海面纹理，不加载第三方图片；不支持 WebGL 时保留 CSS 水波）
- 星光鼠标，手机点击粒子，保留表单与弹窗的原生光标
- 收藏网格 / 扇形 / 圆环，按钮、键盘和拖动切换，原有筛选与详情保留
- 任务进度肥啾、待抽卡波浪、开卡粒子扫光、签到短暂粒子
- 原创地图路径巡游，不改变其他页面的独立导航结构
- OC 预留布局仅为示意，没有创建或宣称真实岛民 OC

统一动效开关与系统减少动态效果均控制新增效果；页面不可见时暂停持续绘制。资源来源、适配与验收边界详见 `MOTION-NOTES.md`。
