## 首页水波蔓延加强

- 海岸波纹从两圈增为三圈，错开3秒，单轮9秒；向外扩散的终点缩放从1.12提高到1.42，白色波缘由2加粗到3。
- WebGL 海面加入两个错开的径向传播波组，加强折射与波峰明暗；时间统一改用秒，避免把毫秒传入移动端片元着色器的中等精度浮点范围。
- 首页点击反馈改为三圈 SVG 涟漪，传播半径与视口对角线关联、持续约3秒；池中最多保留3组，动画完成后移除。所有波纹置于前景文字和按钮之后，其他页面保持原来的短点击反馈。
- 关闭动效立即清理点击涟漪；系统减少动态效果、WebGL 失败后的 CSS 波纹降级保留。
- 本次浏览器检查通过：电脑 WebGL 着色器渲染、海岸三圈扩散、点击半径、数量上限、无横向溢出、统一开关与系统减少动态效果、手机触控与 CSS 降级、画廊页面隔离；无 JavaScript 异常。未据云端软件渲染宣称真实手机硬件性能。

## 参考与实现

1. **水面折射**：参考用户提供的WebGL控制器及GLSL水面迭代噪声。用本地Canvas生成海面纹理代替示例照片，简化噪声迭代与分辨率；失败时降为CSS水纹。无外部图片和lil-gui运行依赖。
2. **流星光标**：借鉴Shooting Star的速度、散开与淡出机制，重写为限量Canvas2D星光；没有引入原例32万粒子、旧Three.js接口或dat.GUI。表单与原生dialog保留系统光标，手机只有点击反馈。
3. **卡库变换**：参考GSAP多形态排列逻辑，用原生坐标计算、CSS过渡与Pointer Events适配16张卡。收藏提供网格、扇形、圆环；原有搜索、筛选、数量和详情保留。
4. **飞行进度**：借鉴飞行滑块航线概念，绘制肥啾和信件；显示真实演示任务数量/9，不能拖动篡改进度。9任务奖励维持待扩展状态。
5. **镜头巡游**：参考5段路线、6段滚动和反向移动焦点。地图为原创SVG，独立导览页有滚动、按钮与跳过入口。无GSAP插件依赖。
6. **无限轮播**：借鉴Osmo示例的循环、惯性停靠、淡化和计数表现，原生帧动画与Pointer Events重写。未复制示例图片、付费字体、外链鼠标资源；不宣称复制Osmo完整组件。
7. **缩略图网格原链接**：完整源码未取得，没有声称复刻；当前卡片详情放大与收回为本地过渡实现。
