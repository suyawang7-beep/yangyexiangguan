# 不吱岛特效分配与适配

日期：2026-10-17。范围：多页面 UI 预览，不接正式后端，不改活动数据规则。

## 首页海岛与毛玻璃更新

- 首页新增原创 `assets/island-scenery.svg`：浅滩、沙滩、绿地、房屋、灯塔与码头，不替代正式 OC 立绘。
- `effects.js` 在首页叠加海岸扩散波纹、漂云、摆动棕榈、浮动帆船与海鸟；岛屿主体不扭曲，WebGL 只绘制背后的海面。
- 首页独立 `island-home.css` 加强玻璃白边、内高光、半透明层与背景模糊；阅读区域保留足够底色，不把文字本身模糊。无背景模糊支持时使用更实的浅色底。
- 动效统一开关、系统减少动态效果和页面隐藏均控制新增持续动画；小屏调整背景取景并降低海面绘制分辨率。
- 未修改通行证、金币、任务、概率、收藏和存储规则。其他页面不加载首页的新样式。
- 本次集中检查：Chromium 下 1440、900、390、360 像素宽度无横向溢出；棕榈动画实际推进；毛玻璃样式与首页 backdrop root 修正通过；动效开关、刷新保存和系统减少动态效果通过；领取通行证后返回首页仍保留编号与50演示金币，按钮正确进入抽卡页；禁用 WebGL 后保留海岛与 CSS 海面；未出现 JavaScript 异常。云端软件渲染不代表真实手机硬件性能。

## 参考与实现

1. **水面折射**：参考用户提供的WebGL控制器及GLSL水面迭代噪声。用本地Canvas生成海面纹理代替示例照片，简化噪声迭代与分辨率；失败时降为CSS水纹。无外部图片和lil-gui运行依赖。
2. **流星光标**：借鉴Shooting Star的速度、散开与淡出机制，重写为限量Canvas2D星光；没有引入原例32万粒子、旧Three.js接口或dat.GUI。表单与原生dialog保留系统光标，手机只有点击反馈。
3. **卡库变换**：参考GSAP多形态排列逻辑，用原生坐标计算、CSS过渡与Pointer Events适配16张卡。收藏提供网格、扇形、圆环；原有搜索、筛选、数量和详情保留。
4. **飞行进度**：借鉴飞行滑块航线概念，绘制肥啾和信件；显示真实演示任务数量/9，不能拖动篡改进度。9任务奖励维持待扩展状态。
5. **镜头巡游**：参考5段路线、6段滚动和反向移动焦点。地图为原创SVG，独立导览页有滚动、按钮与跳过入口。无GSAP插件依赖。
6. **无限轮播**：借鉴Osmo示例的循环、惯性停靠、淡化和计数表现，原生帧动画与Pointer Events重写。未复制示例图片、付费字体、外链鼠标资源；不宣称复制Osmo完整组件。
7. **缩略图网格原链接**：完整源码未取得，没有声称复刻；当前卡片详情放大与收回为本地过渡实现。

## 行为与边界

- `effects.html` 为统一体验入口；`guide.html` 为独立登岛导览；`islanders.html` 为未来OC布局预览。
- 统一开关控制CSS与Canvas动画，尊重系统减少动态效果。
- 页面不可见时暂停持续绘制；鼠标粒子池最多95颗，闲置后停止逐帧更新。
- 收藏默认网格，`collection.html#appreciate` 可直接体验扇形。
- 仍为本地演示，不代表正式账户、真实岛民核验或正式领奖服务。

## 验收

使用本机Chromium集中验收，结果：

- 首页实际创建WebGL着色器并渲染；当前云环境使用SwiftShader软件渲染，不据此宣称真实GPU性能。
- 电脑下的星光光标、关闭动效后的原生光标通过。
- 领证50金币、SR/SSR首抽、扣款、收藏、搜索、筛选、详情弹窗、刷新保存、签到防重与任务阶段奖励通过。
- 收藏扇形/圆环/网格、按钮切换与拖动通过。
- OC画廊循环、鼠标拖动、错落与纵深通过。
- 10页在1440/390宽度，4个关键页在360宽度，共24个页面宽度组合未发现横向溢出。
- 首次综合验收发现手机版导览下一站定位偏移；修正固定地图的锚点计算后，针对性复查下一站/下一站/上一站均通过。
- 带触控模拟的浏览器验证了画廊滑动、收藏切换、导览按钮。
- 录屏检查补充发现960宽度下圆环卡片可能盖住翻页按钮，已将卡片容器设为独立堆叠层，确保控制按钮始终可点。
- 系统减少动态效果可实时关闭新增特效，静态地图仍可导航；关闭时卡库CSS过渡为0秒。
- 验收未捕获页面JavaScript错误。未据此声称真实手机设备、正式素材、跨设备账户或生产环境通过验收。
