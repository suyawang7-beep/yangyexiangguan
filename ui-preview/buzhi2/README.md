# 不吱岛 2.0 · 吱吱生日季独立预览

## 范围
- 独立响应式首页：吱吱生日主角、菜菜陪伴，日期不写死，未确认活动不标注为已开放。
- 主要入口仅指向本预览的正确章节；明确将菜菜生日抽卡展示为往期且暂不开放。
- 融卡与周边商店仅交互草案：选中示例卡牌、切换选项卡、展示规则待确认，提交按钮禁用。
- 无真实抽卡、扣款、兑换、账号认证、数据库或线上 API 请求。

## 运行
独立预览位于 `ui-preview/buzhi2/index.html`。本分支根 `Dockerfile` 专门提供静态 nginx 容器，**不要合并这个 Dockerfile 到 main**，因为 main 使用 Node 服务并挂载真实数据。

## 人工验收待办
- 在 375px、390px、768px、1440px 宽度下检查横向滚动、主视觉和按钮。
- 验证 tab 的鼠标、键盘左右箭头与隐藏面板状态。
- 验证「减少动效」按钮以及 `prefers-reduced-motion`。
- 确认点击禁用的融卡、兑奖按钮不会写入任何内容。
- 确认所有页面均明确标为演示，不使用尚未确认的生日日期、材料比例、库存数量。

## 迁入正式代码的后续工程点（**未实施**）
1. 正式首页需要从 `/api/activity` 获取时段，并配合独立抽卡/兑换活动开关；统一开关尚不足以判断每个活动是否开放。
2. 通行证与认证状态需绑定真实用户，会话信息不可用时展示安全降级入口。
3. 保留菜菜生日历史卡片和记录；旧交易绝不改写。
4. 获得岛主确认规则后再设计真实后端操作、幂等确认和账本审计。
