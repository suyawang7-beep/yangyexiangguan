真实库存与结果由不吱岛服务器确认；不保证升阶，也可能获得已拥有的卡。

  1. 两张已公开、同等级 N / R / SR；可选不同 ID。同 ID 需拥有至少两张，不自动保留一张。
  2. 每天基础3次，另计领取的当日补发次数；按北京时间日期计数，次日 00:00 重置。
  3. N → N / SR / SSR / UR；R → N / R / SSR / UR；SR → 所有五个等级。不保证升阶。
  4. 服务端从符合等级的公开卡中逐张均匀随机选择；不是按稀有度等概率。允许出现已拥有卡，也可能返回材料同 ID。
  5. 仅消耗两张材料并增加一张结果；该函数没有扣金币或额外材料逻辑。
  6. 正式接口要求已认证岛民，requestId 幂等；本页沿用正式认证与幂等接口。
