## 结构与交互

- 七个独立 HTML 页面，通过相对地址导航。共用 CSS 与 JS 保持一致。
- 首页：非对称双人主视觉、庆典日期、根据领证状态变化的主按钮。
- 通行证：昵称、免费头像、唯一参与编号、复制失败的手动选择回退。
- 事务所：免费报到；其余任务需主动启用“岛民操作演示”，不冒充真实核验。
- 签到：按 Asia/Shanghai 日期，每天一次。
- 抽卡：50金币；首抽6张SR/SSR等概率；正常16张等概率。
- 收藏：拥有/未拥有、稀有度、卡名/角色搜索、数量、故事、首获时间及最近记录。
- 岛主信箱：静态公告样例。
- 动效：流动水纹、漂浮、光晕呼吸、玻璃扫光、点击水波、鼠标视差、开卡翻转与显现。统一开关持久保存，尊重系统减少动态效果。
