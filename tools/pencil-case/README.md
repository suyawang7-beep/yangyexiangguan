`python3 tools/build-pencil-assets.py` creates the original Buzhi birthday
subjects (not copies of the example illustrations). Requires Pillow, numpy and
ffmpeg. The engine runs at build time only; browsers receive local PNG/MP4 assets.
No external runtime, analytics, fonts or network calls are added.
The browser interaction and accessible motion controls are project code, not
features supplied by pencil-case. Paper grain is set to zero to respect the
approved clean map/low-saturation design. Only the tiny crayon accent has texture.
