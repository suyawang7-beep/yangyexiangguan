# 不吱岛 · 正式插画素材接入

此目录仅定义素材文件名；**没有默认提供任何角色立绘或卡面**。请使用已获授权的图片，并在上传前确认图像来源与使用范围。

## 立绘（WebP、透明底、建议高度 1600–2400 px）

- `assets/characters/zhizhi.webp`：左侧吱吱，共同岛主
- `assets/characters/caicai.webp`：右侧菜菜，生日主角

建议人物保留全头与肩部，人物居中，底部自然裁切；尽量不留大面积透明边。若资源缺失或加载失败，首页自动保留原来的文字占位。

## 生日卡面（WebP、建议纵向 3:4，最少 900 × 1200 px）

放在 `assets/cards/`：

- UR-1.webp
- SSR-1.webp、SSR-2.webp
- SR-1.webp 至 SR-4.webp
- R-1.webp 至 R-4.webp
- N-1.webp 至 N-5.webp

**一共 16 张**。名称大小写必须精确匹配。抽卡几率不取决于图片文件，有图或无图都仍按既定的首抽 SSR/SR 保底和普通 16 张等概率规则运行。

上传图片到相应路径后，服务端会自动提供 `/assets/characters/*.webp` 和 `/assets/cards/*.webp`；静态站点需连同 assets 文件夹一起部署。没有卡图时自动保留卡片文字占位；未解锁卡片不会提前暴露图片。

## 质量检查

1. 使用透明背景立绘，避免人物在海蓝背景上出现白边。
2. 卡面保持主体在安全区内，避免被卡片边框覆盖；手机端检查标题和脸部。
3. 文件名严格对应编号，WebP 推荐各文件控制在可接受的网页体积。
4. 上传素材前核对版权授权；避免把私人信息放入图片。
5. 上传后运行 GitHub Actions，特别检查抽卡、收藏室、响应式与减少动态模式。

注意：本次提交的是**可运行的素材槽和失败兜底**，未假装已取得或接入正式插画。
